ORBIT — First-person interactive 3D solar system

You drift through the solar system like an astronaut.

Main view
- Immersive first-person camera (dramatic low angle)
- Sun + all 9 planets orbiting at calm, proportional speeds
- Floating name labels
- Drag / touch to look around

Planet pages
- Tap any planet → smooth zoom into a dedicated 3D scene
- The planet is large and close; its major moons orbit around it
- Double-tap → detail panel with facts
- Triple-tap → return to the full solar system

Fully responsive. Pure WebGL, no external libraries.

Deploy to Netlify
1. Unzip the folder containing index.html
2. Go to https://app.netlify.com/drop
3. Drop the folder
